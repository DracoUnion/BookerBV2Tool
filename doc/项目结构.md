# BookerBV2Tool 代码结构

BV2 声音克隆助手（切片 → 重采样 → 标注 → 建表 → 预处理 → BERT 特征 → 训练 → 推理全流程）。

命令行入口来自 `pyproject.toml` `[project.scripts]`：`BookerBV2Tool` 与 `bv2-tool`，均指向 `BookerBV2Tool.__main__:main`。

代码全部位于 `BookerBV2Tool/` 包内，按职责分为 5 类模块：

## 1. 入口与命令注册

+ `__main__.py` — 唯一入口。构建顶层 `argparse` 解析器（含 SenceVoice 路径、中/英/日 BERT 模型等公共参数），注册 `slice`、`resample`、`mark`、`mklist`、`preproc`、`bert-gen` 六个直接子命令，以及惰性导入的 `train`、`infer` 两个子命令（train 依赖 tensorboard 与上游 Bert-VITS2 组件，故按需导入，避免拖垮其它子命令启动），最后 `args.func(args)` 派发。
+ `__init__.py` — 包元信息。

## 2. 音频预处理

+ `slice.py` — `slice` 命令：基于 RMS 能量的 VAD 静音切片，将长音频切分为短片段。
+ `resample.py` — `resample` 命令：多线程重采样（librosa/soundfile），统一采样率。
+ `mark.py` — `mark` 命令：SenseVoice ASR 标注，把音频转写为 `.txt` 字幕（单文件/目录，异常安全）。
+ `mklist.py` — `mklist` 命令：从目录中的 WAV + 配套 TXT 生成 `speaker_list.json`（file/role/lang/sub）。
+ `preproc.py` — `preproc` 命令：文本清洗与多语言前端（clean_text/chinese/japanese/english），生成 phones/tones/word2ph 并写入 train/val 列表。

## 3. 模型训练与推理

+ `bert_gen.py` — `bert-gen` 命令：多进程生成 BERT 特征向量并保存为 `_bert.pt`。
+ `train.py` — `train` 命令：Bert-VITS2 训练（生成器/多周期判别器/时长判别器/WavLM 判别器，混合精度 + tensorboard）。
+ `infer.py` — `infer` 命令：文本转语音推理（SynthesizerTrn 加载 `G_*.pth` 检查点，合成 WAV）。
+ `commons.py`/`losses.py`/`models.py`/`modules.py`/`attentions.py`/`data_utils.py`/`mel_processing.py`/`transforms.py`/`config.py` — 从上游 Bert-VITS2 移植的核心组件（模型结构、损失函数、数据加载器、熔滤波组等），本仓库固定模型版本 2.3。

## 4. 语音识别

+ `sencevoice.py` — SenseVoice/FunASR 语音识别，供 `mark` 子命令使用（VAD 分段 + 多语言自动检测）。

## 5. 工具与子目录

+ `utils.py` — 通用工具函数。
+ `text/` — 多语言文本前端（cleaner、chinese/japanese/english、symbols）。
+ `monotonic_align/` — 对齐模块（上游组件）。
+ `tools/` — 辅助工具脚本。
+ `tests/` — pytest 测试（`.pytest_cache` 表明有 pytest 测试）。
+ `doc/` — 已有 `01-architecture.md`…`07-configuration.md` 与 `README.md`；本文档为新增。
